백준 1062번 · 가르침

비트마스크 + 조합 탐색(DFS·백트래킹) | 읽으면서 이해하는 C언어 학습자료

학습 순서

1. 문제를 쉽게 이해하기

남극의 선생님은 영어 소문자 26개 중 K개를 가르칠 수 있습니다. 학생은 자신이 배운 글자로만 이루어진 단어를 읽을 수 있습니다. N개의 단어 중 가장 많은 단어를 읽게 하려면 어떤 글자를 선택해야 할까요?

목표: 정확히 K개의 서로 다른 글자를 가르쳐서, 읽을 수 있는 단어 수를 최대화합니다.
조건의미
1 ≤ N ≤ 50검사할 단어는 최대 50개
0 ≤ K ≤ 26가르칠 수 있는 서로 다른 알파벳 수
단어 길이 8~15모든 단어는 anta로 시작하고 tica로 끝남
출력읽을 수 있는 단어 수의 최댓값

2. 가장 중요한 예외 처리

모든 단어에 반드시 필요한 글자는 a, n, t, i, c의 5개입니다.

상황정답 / 처리이유
K < 50공통 필수 글자를 다 가르칠 수 없음
K = 5추가 글자가 없는 단어 수필수 5개만 가르침
K = 26N모든 알파벳을 가르칠 수 있음
K−5 ≥ 실제 추가 후보 수N단어에 등장하는 나머지 글자를 모두 가르칠 수 있음
K=5일 때 정답이 무조건 0인 것은 아닙니다. 예를 들어 antatica는 필수 5개만으로 읽을 수 있습니다.

3. 비트마스크란?

알파벳 26개를 정수의 26개 비트에 하나씩 대응시킵니다. a는 0번 비트, b는 1번, …, z는 25번 비트입니다. 어떤 글자가 포함되면 해당 비트를 1로 설정합니다.

글자 ch의 비트 = 1 << (ch - 'a')
C 표현식뜻
1 << (ch - 'a')글자 ch의 비트 하나 만들기
mask |= 1 << (ch - 'a')집합에 글자 추가
mask & ~basic필수 글자 제거
(word & taught) == word단어의 필요 글자가 모두 포함되었는지 확인

비트를 직접 켜고 끄기

아래 글자를 눌러 보세요. 선택한 알파벳이 비트마스크로 변환됩니다.

4. 왜 필수 글자를 제외할까? (확장 상세 설명)

4-1. 모든 단어는 같은 부분으로 시작하고 끝납니다

anta + 중간 글자 + tica

시작 부분 anta에 등장하는 글자는 a, n, t입니다. 끝 부분 tica에 등장하는 글자는 t, i, c, a입니다. 중복을 제거하면 a, n, t, i, c의 다섯 글자만 남습니다. 따라서 단어를 하나라도 읽으려면 이 다섯 글자를 모두 배워야 합니다.

4-2. K=6이면 추가로 한 글자만 가르칠 수 있습니다

전체 K − 필수 5개 = 추가 선택 가능 글자 수
6 − 5 = 1개

이제 26개 전체에서 6개를 고를 필요가 없습니다. 필수 5개를 미리 확정하고, 나머지 21개 중 1개만 고르면 됩니다.

4-3. 예제 1을 표로 분석합니다

3 6
antarctica
antahellotica
antacartica
단어필수 5개 제외 후 필요한 글자r을 추가하면?
antarcticar읽을 수 있음
antahelloticah, e, l, o읽을 수 없음
antacarticar읽을 수 있음

r을 가르치면 첫 번째와 세 번째 단어를 읽어 2개를 얻습니다. 반면 h, e, l, o 중 하나만 가르쳐서는 두 번째 단어를 읽을 수 없습니다. 필요한 네 글자를 모두 배워야 하기 때문입니다.

중요: 글자가 여러 번 등장해도 한 번만 가르치면 됩니다. antahellotica의 l이 두 번 나와도 필요한 글자 집합에는 l이 한 번만 들어갑니다.

4-4. 탐색 범위는 얼마나 줄어들까요?

필수 글자 5개를 제외하면 후보는 최대 21개입니다. K=8이라면 추가로 3개를 선택하므로 조합 수는 다음과 같습니다.

C(21, 3) = 21 × 20 × 19 ÷ (3 × 2 × 1) = 1330

실제 구현에서는 단어에 한 번도 등장하지 않는 글자도 후보에서 제외하므로 탐색을 더 줄일 수 있습니다.

6. DFS로 글자 조합을 고르기

dfs(idx, count, mask)는 idx번째 후보부터 검사하고, 지금까지 count개를 골랐으며, mask는 선택한 글자의 집합이라는 뜻입니다.

선택한다
dfs(idx + 1,
    count + 1,
    mask | bit);

현재 글자를 추가하고 다음 후보로 이동합니다.

선택하지 않는다
dfs(idx + 1,
    count,
    mask);

현재 글자를 건너뛰고 다음 후보로 이동합니다.

선택한 글자 수가 K-5개가 되면, N개 단어를 모두 검사해 읽을 수 있는 단어 수를 계산합니다.

DFS의 선택 과정을 단계별로 살펴보기

후보 글자 b, d, r 중 2개를 선택하는 연습입니다. 실제 문제와 같은 선택 / 미선택 분기 구조를 사용합니다.

가지치기: 남은 후보 글자 수가 앞으로 더 골라야 할 글자 수보다 적으면 그 경로에서는 정답 조합을 만들 수 없으므로 즉시 종료합니다.

7. C언어 정답 코드 전체

실제로 단어에 등장하는 후보 글자만 탐색합니다. C(GCC)로 제출할 수 있습니다.

#include <stdio.h>

int N, K;
int words[50];
int letters[21];
int letterCount = 0;
int answer = 0;

void dfs(int idx, int count, int mask)
{
    if (count == K - 5)
    {
        int readable = 0;
        for (int i = 0; i < N; i++)
        {
            if ((words[i] & mask) == words[i])
                readable++;
        }
        if (readable > answer)
            answer = readable;
        return;
    }

    if (idx == letterCount)
        return;

    if (letterCount - idx < K - 5 - count)
        return;

    dfs(idx + 1, count + 1,
        mask | (1 << letters[idx]));
    dfs(idx + 1, count, mask);
}

int main(void)
{
    scanf("%d %d", &N, &K);

    int basic = 0;
    basic |= 1 << ('a' - 'a');
    basic |= 1 << ('n' - 'a');
    basic |= 1 << ('t' - 'a');
    basic |= 1 << ('i' - 'a');
    basic |= 1 << ('c' - 'a');

    int used = 0;
    for (int i = 0; i < N; i++)
    {
        char s[20];
        scanf("%19s", s);
        int mask = 0;
        for (int j = 0; s[j] != '\0'; j++)
            mask |= 1 << (s[j] - 'a');

        words[i] = mask & ~basic;
        used |= words[i];
    }

    if (K < 5)
    {
        printf("0\n");
        return 0;
    }
    if (K >= 26)
    {
        printf("%d\n", N);
        return 0;
    }

    for (int i = 0; i < 26; i++)
    {
        if (used & (1 << i))
            letters[letterCount++] = i;
    }

    if (K - 5 >= letterCount)
    {
        printf("%d\n", N);
        return 0;
    }

    dfs(0, 0, 0);
    printf("%d\n", answer);
    return 0;
}

8. 핵심 코드 한 줄씩 해설

words[i] = mask & ~basic;

단어에 포함된 전체 글자에서 공통 필수 글자를 제거하고, 추가로 필요한 글자 집합만 저장합니다.

used |= words[i];

모든 단어에 실제로 등장하는 추가 글자를 모읍니다. 등장하지 않는 글자는 가르쳐도 읽을 수 있는 단어가 늘지 않으므로 DFS 후보에서 제외합니다.

letters[letterCount++] = i;

실제로 사용된 추가 글자의 알파벳 번호만 후보 배열에 기록합니다.

mask | (1 << letters[idx])

현재 후보 글자를 배운 글자 집합에 추가합니다.

(words[i] & mask) == words[i]

단어에 필요한 모든 추가 글자가 배운 글자에 포함되면 참입니다. AND 연산 결과가 원래 필요 글자 집합과 같기 때문입니다.

letterCount - idx < K - 5 - count

앞으로 남은 후보 개수보다 더 많이 골라야 하는 경우이므로 해당 DFS 분기를 중단합니다.

9. 알고리즘이 정확한 이유

  1. 어떤 단어를 읽으려면 필수 글자 5개가 반드시 필요합니다.
  2. K가 5 이상이라면 필수 5개를 먼저 고르는 것이 최적해를 놓치지 않습니다. 필수 글자 하나라도 빠지면 어떤 단어도 읽을 수 없기 때문입니다.
  3. 실제로 등장하는 추가 글자만 탐색해도 됩니다. 등장하지 않는 글자를 선택해도 읽을 수 있는 단어 수는 변하지 않습니다.
  4. DFS는 추가 글자 K−5개를 고르는 모든 가능한 조합을 빠짐없이 검사합니다. 필요한 경우 남는 선택 자리는 등장하지 않는 글자로 채워도 됩니다.
  5. 각 조합에서 읽을 수 있는 단어 수를 정확히 세고 최댓값을 취하므로 최적해를 얻습니다.

10. 시간·공간 복잡도

실제로 등장하는 추가 후보 글자 수를 L(최대 21), 추가로 선택할 글자 수를 R=K−5라고 하겠습니다.

시간: O(N × C(L,R)) (완성 조합 검사 기준)
공간: O(N + L)

DFS의 중간 노드 탐색 비용도 있으므로 전체 시간은 정확히는 O(N × C(L,R) + DFS 방문 노드 수)입니다. L이 최대 21이므로 조합 탐색으로 해결할 수 있습니다.

12. 정답·해설 및 최종 정리

문제 1: K=4이면 정답은 0입니다. 필수 5개를 다 가르칠 수 없기 때문입니다.

문제 2: K=5일 때 antarctica는 읽을 수 없습니다. r이 추가로 필요합니다.

문제 3: K=6이면 antarctica와 antabtica를 동시에 읽을 수 없습니다. r과 b가 모두 필요해 총 7개를 가르쳐야 합니다.

문제 4: (words[i] & mask) == words[i]는 단어에 필요한 모든 추가 글자를 배웠다는 뜻입니다.

문제 5: 후보 7개 중 2개를 고르는 조합은 C(7,2)=21개입니다.

최종 핵심: 필수 글자 5개를 먼저 고정 → 단어에서 필수 글자 제거 → 실제 사용된 나머지 글자만 수집 → DFS로 조합 선택 → 비트 AND로 읽기 가능 여부 확인 → 최댓값 출력.
